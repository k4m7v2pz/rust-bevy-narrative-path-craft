# Narrative Path Craft

**Rust + Bevy 叙事驱动 2D RPG 引擎** — 当前为占位仓库（壳），引擎本体正由示例游戏驱动演化中。

---

## 核心思想：引擎从可玩示例中分离

引擎不是凭空设计出来的，而是**从可试玩、可排错的真实示例中沉淀出来的**。

- 一个引擎必须要有**例子**——能试玩、能排错、能验证玩法与能力边界，才能把"引擎"从"游戏"里分离出来。
- 本引擎的载体示例是 **Endless Corridor（无尽回廊）**：
  - 仓库：`k4m7v2pz/rust-bevy-endless-corridor`
  - 它在真实地使用引擎的设计语言（线性时间轴剧本 / 分支对话 / 结局注册 / 存档等），是引擎能力的第一手验证场。
- 引擎与示例的关系是**互相塑造**的：
  - 示例为引擎提供真实需求与边界；
  - 引擎为示例提供可复用的叙事基础设施；
  - 当示例稳定、能力边界清晰后，把引擎核心代码从示例中抽离回本仓库。

## 引擎候选核心（从示例中沉淀）

以下模块业务无关、可复用，最有资格进入引擎：
- 线性时间轴剧本演出（对应示例 `narrative.rs`）
- 分支对话图（对应示例 `dialogue.rs`）
- 结局注册与触发（对应示例 `endings.rs`）
- 存档系统（对应示例 `save.rs`）

具体游戏逻辑（地图生成、玩家/怪物、战斗等）留在示例中。
